# Проект: Предсказание снижения активности клиентов интернет-магазина «В один клик»

## Постановка задачи
Интернет-магазин «В один клик» заметил снижение активности постоянных клиентов.  
Цель проекта — построить модель машинного обучения, которая прогнозирует вероятность снижения активности клиента на основе его поведения: покупок, посещений сайта и истории взаимодействия с сервисом.  
Это позволит вовремя выявлять «остывающих» клиентов и формировать персонализированные меры удержания.

## Данные
В проекте используются следующие файлы:
- `market_file.csv` — основная таблица с признаками поведения клиентов.
- `market_money.csv` — данные о покупках.
- `market_time.csv` — время активности на сайте.
- `money.csv` — прибыль по клиентам.

## Используемые модели
В проекте рассматриваются несколько алгоритмов:
- Logistic Regression  
- Decision Tree  
- Random Forest  
- KNN  
- SVC  
Все модели сравниваются с помощью метрики ROC-AUC. Подбор гиперпараметров выполняется через GridSearchCV.

## Результаты
Лучшая модель по ROC-AUC: SVC (C=0.5, gamma='scale').
Она даёт наилучший баланс между качеством и обобщающей способностью и может использоваться для прогнозирования риска снижения клиентской активности.
